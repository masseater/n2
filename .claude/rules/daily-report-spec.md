# 日報機能仕様

## データ構造

日報はタスク主軸で設計する。

```
タスクA
  - 昨日やったこと: [入力欄]
  - 今日やること: [入力欄]

タスクB
  - 昨日やったこと: [入力欄]
  - 今日やること: [入力欄]
```

## 表示条件

日報ページに表示するタスクの条件:

1. **In Progress / TODO のタスク** → 表示
2. **Done のタスク** → 表示しない
3. **手動で日報に追加されたタスク** → ステータスに関わらず表示

## DB設計

### daily_report_tasks テーブル

タスクごとの日報エントリー:

- `yesterdayNote`: そのタスクで昨日やったこと
- `todayNote`: そのタスクで今日やること

## ビュー優先度

- デフォルトビュー: 日報
- タブ順序: 日報 > リスト > ボード
