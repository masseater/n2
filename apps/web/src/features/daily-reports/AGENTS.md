# daily-reports feature

タスク主軸の日報管理を担当。

## 責務

- 日付ごとの日報 CRUD
- タスクごとの「昨日やったこと」「今日やること」の記録
- 日報からのタスクステータス変更（即時反映 + 履歴記録）

## 表示条件

日報に表示するタスク:
- In Progress / TODO → 表示
- 昨日/今日 Done になったタスク → 表示
- 2日以上前に Done → 非表示
- 手動追加されたタスク → ステータスに関わらず表示

## 自動引き継ぎ

昨日の「今日やること」が今日の「昨日やったこと」のデフォルト値になる。

## ステータス変更

日報からステータスを変更すると:
1. タスク本体を即座に更新
2. 日報エントリに履歴として記録
3. リストビュー・カンバンボードに即座に反映
