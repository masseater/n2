# tasks feature

タスクの CRUD・階層管理・ステータス管理・タグ管理を担当。

## 責務

- タスクの作成・更新・削除（アーカイブ方式）・復元
- 無限階層の親子関係管理（materialized path）
- ドラッグ&ドロップによる並べ替え・階層移動
- ステータス管理（TODO / In Progress / Done + カスタム）
- タグの付与・削除

## データモデル

- タスクは無限階層（ルートタスク = プロジェクト）
- 階層は materialized path で管理
- 削除はハードデリートではなくアーカイブテーブルに移動
- Done に変更すると `completedAt` が自動設定される
